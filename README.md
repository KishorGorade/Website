# cyberSKA — Purposeful Motion Website

This package makes every animation explain part of the cyberSKA security operating method. It is designed to make visitors understand visibility, detection, investigation, response, and improvement—not merely observe decorative effects.

## Purposeful interactions
- Hero story controls move through the five-stage security operating method.
- The method cards control the same story so motion and content stay connected.
- Capability nodes reveal the role each capability plays.
- Service cards connect technical scope to a business outcome.
- Scroll progress shows the visitor’s position through the narrative.
- The ticker reinforces the operating vocabulary.
- Reduced-motion preferences disable decorative animation.
